Compares two configuration files and shows a difference.

## Build
``` make
make build
```

## Install
``` make
make inslall
```

## Run
``` make
make run-dist
```

## Run with arguments
``` make
make run-dist ARGS="pathToFile1 pathToFile2 formatName"
```

## Run tests
``` make
make test
```
